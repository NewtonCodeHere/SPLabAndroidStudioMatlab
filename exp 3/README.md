# Experiment 3: Root Finding (Newton-Raphson Method)

## Aim
To design and implement a native Android application using Java that calculates the square root of a number using the Newton-Raphson Method and displays the step-by-step convergence across sequential iterations on the user interface.

## Procedure
1. Create a new Android project using Java.
2. In `activity_main.xml`, add a `TextView` to display the step-by-step iteration results.
3. In `MainActivity.java`, compute the Newton-Raphson iterations using the formula `x = (x + n / x) / 2` and display the results in the `TextView`.

## Output
```
Iteration 1 = 1.4166666666666665
Iteration 2 = 1.4142156862745097
Iteration 3 = 1.4142135623746899
Iteration 4 = 1.414213562373095
Iteration 5 = 1.414213562373095
```
